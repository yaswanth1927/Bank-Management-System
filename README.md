# 🏦 Bank Management System

## 📌 About the Project
The Bank Management System is a Java-based application designed to
manage bank accounts and perform basic banking operations.
It demonstrates Object-Oriented Programming (OOP) concepts in Java.

## 🚀 Features
- Create and manage bank accounts
- Deposit money
- Withdraw money
- Display account details
- Support different account types

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE

## 🎯 Learning Objectives
- Classes and Objects
- Inheritance
- Polymorphism
- Method Overriding
- Encapsulation
